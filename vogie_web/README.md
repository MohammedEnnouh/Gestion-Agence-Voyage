# Vogie - Agence de Voyage Management App

A beautiful and modern Android application for managing a travel agency, built with Java and Material Design.

## Features

### 🏠 Dashboard
- Overview of key statistics (total clients, active reservations, monthly revenue)
- Popular destinations list with ratings and prices
- Beautiful card-based layout with modern design

### 👥 Clients Management
- View all clients with their contact information
- Client status indicators (Active/Inactive)
- Clean and organized client list

### 📅 Reservations Management
- Track all reservations with client details
- Reservation status tracking (Confirmée, En attente, Annulée)
- Price and date information for each reservation

### 🌍 Destinations Management
- Browse available travel destinations
- View destination details, prices, and ratings
- Popular destinations showcase

### 📊 Reports
- Sales reports and analytics
- Client statistics
- Destination performance reports
- Revenue tracking

## Design Features

### 🎨 Modern UI/UX
- **Material Design 3** components
- **Beautiful color scheme** with blue primary colors and orange accent
- **Card-based layouts** for better organization
- **Smooth navigation** with bottom navigation bar
- **Floating Action Button** for quick actions

### 🧭 Navigation
- **Top toolbar** with centered logo and app name
- **Bottom navigation** with 5 main sections
- **Fragment-based architecture** for smooth transitions
- **Responsive design** that works on different screen sizes

### 🎯 Key Design Elements
- **Centered logo** in the top navigation bar
- **Consistent color scheme** throughout the app
- **Elevated cards** with shadows for depth
- **Status indicators** with color coding
- **Clean typography** with proper hierarchy

## Technical Stack

- **Language**: Java
- **UI Framework**: Android Views with Material Design
- **Architecture**: Fragment-based navigation
- **Layout**: ConstraintLayout and LinearLayout
- **Components**: RecyclerView, CardView, BottomNavigationView
- **Icons**: Vector drawables for crisp display

## Getting Started

1. Open the project in Android Studio
2. Sync the project with Gradle files
3. Build and run the application on an Android device or emulator
4. The app will start with the Dashboard screen

## Color Scheme

- **Primary**: Blue (#1976D2) - Main brand color
- **Primary Dark**: Dark Blue (#1565C0) - Status bar and accents
- **Accent**: Orange (#FF5722) - Call-to-action elements
- **Background**: Light Gray (#F5F5F5) - App background
- **Success**: Green (#4CAF50) - Positive status indicators
- **Warning**: Orange (#FF9800) - Caution elements
- **Error**: Red (#F44336) - Error states
